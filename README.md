## DIPLOM

Интерактивный консольный помощник для определения года использования военных артефактов периода ВОВ (1941–1945) 
на основе экспертного дерева решений и распознавания изображений через TensorFlow Lite.


### Назначение
Проект помогает исследователям, поисковым отрядам и коллекционерам определить вероятный год изготовления найденного военного предмета (пуговицы, знаки, звезды) по двум источникам:
- Экспертные знания — интерактивное дерево вопросов о размере, месте обнаружения, количестве и звании владельца
- Машинное обучение — классификация изображения предмета через TFLite-модель с последующим сопоставлением с каталогом артефактов
Результат: отфильтрованный список годов (например, [1943] или [1941, 1942]), в которые предмет мог использоваться.


### Схема проекта
```
┌─────────────────────────────────────────┐
│ 1. Пользователь отвечает на вопросы     │
│    • Размер пуговицы: 10 или 14 мм?     │
│    • Место на форме: шея, грудь, плечо? │
│    • Звание владельца: известно?        │
└────────────────┬────────────────────────┘
                 │
                 ▼
┌─────────────────────────────────────────┐
│ 2. Система сужает диапазон годов        │
│    на основе экспертных правил          │
│    (массив "statement" в JSON)          │
└────────────────┬────────────────────────┘
                 │
                 ▼
┌─────────────────────────────────────────┐
│ 3. Опционально: загрузка изображения    │
│    • TFLite-модель предсказывает класс  │
│    • Каталог recognition.json даёт      │
│      годы для этого класса + место      │
└────────────────┬────────────────────────┘
                 │
                 ▼
┌─────────────────────────────────────────┐
│ 4. Объединение результатов:             │
│    • Пересечение годов из вопросов      │
│      и распознавания (если есть)        │
│    • Если пересечение пусто — объединение│
└────────────────┬────────────────────────┘
                 │
                 ▼
┌─────────────────────────────────────────┐
│ 5. Итог: [1943] или [1941, 1942, 1943] │
└─────────────────────────────────────────┘
```

## Форматы данных

### 1. Дерево вопросов - pugovica.json
Иерархическая структура с узлами вида:
```
{
  "question": "Какого она размера? 10 или 14",
  "answers": {
    "10": {
      "statement": [1941, 1942, 1943, 1944, 1945],
      "question": "Около какой части тела: ШЕЯ(neck), ГРУДЬ(chest)...?",
      "answers": { ... }
    },
    "14": { ... }
  },
  "statement": [1941, 1942, 1943]
}
```
Специальные команды в answers:
- "RETURN_STATEMENT" — завершить диалог, вернуть текущие годы
- "RECOGNITION_STATEMENT" — перейти к режиму распознавания изображений

### 2. Каталог артефактов - recognition.json
Справочник классов, возвращаемых ML-моделью:
```
{
  "2": {
    "where": {
      "neck": [1941, 1942, 1943],
      "shoulder": [1943, 1944, 1945]
    },
    "size": "25x15mm",
    "description": "Знак в петлицу или погон танковых войск",
    "range": ["рядовой", "младший командир", "средний командир"],
    "ask_more": true
  }
}
```

### Запуск
```bash
./artifact_dater pugovica.json recognition.json model.tflite classes.json
```
Аргументы:
- questions.json - лежит в корне проекта
- recognition.json - лежит в корне проекта
- model.tflite - лежит по пути от корня проекта: `data_for_tests/DIPLOM/models/model.tflite`
- classes.json - лежит по пути от корня проекта: `data_for_tests/DIPLOM/classes.json`


Основной файл: `main.cpp`
На первом этапе будут задаваться вопросы и предлагаться варианты ответов, 
которые можно на них ввести (из файла pugovica.json).
Затем, если пользователь хотел добавить информации из изображений, 
которая программа должна распознать и классифицировать, добавляется информация из recognition.json, 
которая есть по тому классу изображений, который удастся получить в процессе распознавания.

## Результат
Логика: если годы из разных источников пересекаются — это наиболее надёжный результат. 
Если нет — показываем все возможные варианты.
